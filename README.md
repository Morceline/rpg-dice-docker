# 🎲 Simulador de Dado

Este é um simulador que gera resultados de dados de forma totalmente aleatória, construído com Python e Flask, e empacotado em um container isolado.

---

## 🐋 Imagem no Docker Hub

A imagem deste simulador:

* **Link do Repositório:** [://docker.com](https://://docker.com)
* **Comando para Baixar (Pull):**
  ```bash
  docker pull jackelinejp/dado-epico:v5
  ```
